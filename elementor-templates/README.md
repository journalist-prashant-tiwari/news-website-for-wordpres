# AIM-PACT Political Strategy Page — Direct Elementor Import

## Import this JSON directly

1. Download **`aim-pact-political-strategy-campaign-management.json`** exactly as it is — **do not unzip, rename, or open and resave it**.
2. In WordPress, go to **Templates → Saved Templates → Import Templates** (or open the Elementor editor, click the folder icon, then **Import Templates**).
3. Select the JSON file. Elementor will add **Political Strategy & Campaign Management | AIM-PACT** to **My Templates**.
4. Create the page `/political-strategy-campaign-management/`, choose **Edit with Elementor**, click the folder icon → **My Templates**, and insert the template.
5. Set the WordPress page title to **Political Strategy & Campaign Management** and publish.

## Compatibility

This is a **single native Elementor page-template JSON export** (not a Template Kit, WordPress XML, or ZIP). It uses Elementor Free widgets only: Section, Column, Heading, Text Editor, Button, Image, Tabs, Accordion, Counter, Icon, and HTML. It has the standard Elementor export fields: `version`, `title`, `type`, `content`, `page_settings`, and `status`.

> **Before publishing:** replace the two external Unsplash placeholders with AIM-PACT-owned images and check all internal `/.../` links. The import file includes responsive presentation CSS in one native Elementor HTML widget.
